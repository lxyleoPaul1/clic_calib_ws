\section{Separable Two-Stage Calibration Framework}
\label{sec:framework}

\subsection{Problem setup}
Consider $L$ \textbf{roadside} LiDARs rigidly mounted on fixed posts and a UAV with
RTK-anchored body frame $\{B\}$---the UAV carries \textbf{no onboard LiDAR}.
Each roadside sensor $\ell$ has unknown pose $T_{L_\ell W}\in SE(3)$ in the RTK world
(ENU) frame.
During a calibration flight, RTK fixes the body trajectory $T_{WB}(t)$; each roadside
LiDAR observes points on the \textbf{UAV hull} (board-free target).
We seek $\{T_{L_\ell W}\}$ and a consistent $T_{WB}(t)$ without calibration boards.

\subsection{Stage-1: RTK-anchored trajectory fitting}
Stage-1 estimates a continuous-time body trajectory $\hat{T}_{WB}(t)$ from RTK
position measurements (and optional attitude streams).
At 10\,Hz, Prais--Winsten whitening improves antenna RMSE to 27.3\,mm (36.0\,mm for
uniform AR(1) scaling; $\sim$125\,mm for naive inflation; simulation); at 0.5\,Hz it
disables automatically ($\Delta t\geq 0.2$\,s).
The output trajectory is \textbf{frozen} before any extrinsic refinement.
Fig.~\ref{fig:framework} summarizes this data flow.

\subsection{Stage-2: frozen-trajectory extrinsic refinement}
Given frozen $\hat{T}_{WB}(t)$, Stage-2 minimizes a nonlinear least-squares cost over
$T_{L_\ell W}$ using body-cluster centroid factors and, when the aspect gate opens,
an observed-mean lever $\mathbf{p}_B$ (Sec.~\ref{sec:mechanism}).
Each post is solved in an \textbf{independent} optimization scope with no shared
state across sensors, preventing cross-sensor leakage in multi-LiDAR batches.

\subsection{Multi-LiDAR composition without FOV overlap}
For diagonal deployment (e.g., NE and SW corner posts), sensors need not see the
same scene.
Per-sensor poses $\hat{T}_{L_\ell W}$ are estimated separately; the relative transform
is composed post hoc:
\begin{equation}
  \hat{T}_{L_{\mathrm{SW}}\leftarrow L_{\mathrm{NE}}}
  = \hat{T}_{L_{\mathrm{SW}}W}\,\hat{T}_{L_{\mathrm{NE}}W}^{-1}.
  \label{eq:rel_compose}
\end{equation}
In simulation, end-to-end multi-post errors match per-sensor solo solves; across ten
seeds the NE/SW sectors are statistically comparable (Sec.~\ref{sec:sim}), with the
frozen anchor reported only as a regression check.
